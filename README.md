To measure the distance between an object and the ultrasonic sensor using sound waves and display the distance in centimetres.

INTERN ID:CIS207

Ultrasonic Distance Meter
Introduction
The Ultrasonic Distance Meter is an embedded systems project used to measure the distance between an object and the sensor.

Components Required
Arduino UNO
HC-SR04 Ultrasonic Sensor
Breadboard
Jumper Wires
USB Cable
Working Principle
The ultrasonic sensor sends sound waves towards an object and receives the reflected waves. Arduino calculates the distance based on the time taken by the waves to return.

Applications
Object Detection
Robotics
Car Parking Systems
Obstacle Detection
Distance Measurement
Technologies Used
Embedded Systems
Arduino IDE
C++ Programming
Ultrasonic Sensor
Conclusion
This project provides a simple and effective method of measuring distance using ultrasonic technology and Arduino.
